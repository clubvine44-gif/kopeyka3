# FINA Native

Новая независимая реализация FINA на Android Java без WebView, аккаунтов, cloud AI, Рациона и Магнита.

## Статус
Экспериментальный нативный прототип 0.1. Не готовый релиз и **не обновление** установленного app.fin.kopeyka.
Application ID: app.fin.fina. Существующие финансовые данные не мигрируются автоматически.

Состав:
- Ledger: локальные доходы и расходы; простой баланс, история, экспорт/импорт в собственном JSON формате.
- MainActivity: четыре нативных раздела, диалоги операций, настройки.
- FinOrbView: Canvas spatial orb с 3D-проекцией, глубиной и управлением жизненным циклом.
- FinVoice: интерфейс голосовых команд, Android SpeechRecognizer как временный адаптер (не гарантирует offline), подтверждение операций.

Старый исходник: https://github.com/clubvine44-gif/kopeyka3 (main b27fdb85)
Архив старого исходника на ПК: G:\AndroidDev\FINA-main-source.zip

## До выпуска в прод
1. Интегрировать настоящую offline ASR (Vosk/sherpa-onnx) и проверить на Realme C55.
2. Написать конвертер старых пользовательских данных, тесты на миграцию, копирование перед обновлением.
3. Вернуть календарь смен, резервы, цели, долги и прогнозы в нативном виде.
4. Провести нагрузочные и lifecycle тесты, устранить проблемы.
5. Согласовать идентификатор пакета и подпись, сделать релиз с механизмом обновления.

Нельзя выпускать этот прототип как полноценную замену существующей Финны.
