# FINA Native — профессиональная переработка

Нативный Android-проект (Java, View, Canvas), **без WebView**. Исходный проект: https://github.com/clubvine44-gif/kopeyka3; изменения в ветке rewrite/fina-native-20261109.

## Уже реализовано в экспериментальном прототипе
- Финансовое ядро: доходы, расходы, категории, баланс, месяц, история.
- Раздел плана: график 2 дневные / 2 ночные / 2 выходных, ставки, прогноз зарплаты.
- Регулярные платежи, цели, резервы, подсчёт свободного остатка.
- Нативные экраны, диалоги с подтверждением, импорт/экспорт JSON v2.
- Собственный пространственный Canvas-персонаж с вращением и глубиной, пауза при уходе приложения в фон.
- Встроенный автономный ASR Vosk на русском языке с подтверждением финансовых команд; модель 45 МБ скачана на ПК и в CI добавляется в APK после проверки SHA-256.
- Числительные прописью («четыре тысячи восемьсот») преобразуются в суммы.
- Нет аккаунтов, ИИ-провайдеров, Рациона, Магнита и внешних сервисов.

## Важно
Это **предварительная версия**, не замена установленного приложения. Application ID: app.fin.fina, в исходном приложении app.fin.kopeyka. Файлы прежнего пользователя не мигрируют автоматически. Подпись продакшн-релиза, совместимость старых архивов, реальное поведение на телефоне, стабильность графики на Realme C55 ещё требуют проверки.
Конечный релиз должен включать все старые функции (долги, планирование, отчёты и др.), а также полноценную миграцию.
