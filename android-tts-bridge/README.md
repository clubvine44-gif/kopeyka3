# Android TTS bridge — тестовый протокол

Этот каталог пока содержит только спецификацию тестового моста для SherpaTTS.

Цель: проверить передачу текста из Копейки в Android-компонент, который вызывает выбранный системный TTS/SherpaTTS.

Протокол v1:
- action: `com.kopeyka.TTS`
- extra: `text` — UTF-8 текст для озвучивания
- extra: `requestId` — идентификатор запроса

До создания APK финансовая логика Копейки и основной веб-код не изменяются.
