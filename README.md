# Копейка 3

Личные финансы под сменный график.

## Модель денег

- **Касса** — накопительный остаток: старт + доходы − расходы − пополнения резервов. **Не обнуляется** в новом месяце.
- **Доступно** = касса − будущие расходы месяца − долги к оплате − резервы к отложить.
- **Сегодня** = доступно ÷ оставшиеся дни месяца.
- Долги **не** минусуют кассу повторно (оплата долга = обычный расход).
