# Копейка 3 / Финна

Личные финансы: смены, касса с переносом, резервы, долги, облако.

## Логика кассы
- **Касса** = начальный остаток + доходы − расходы − депозиты в резервы + выводы
- Остаток **не обнуляется** в новом месяце — переносится
- Долги влияют на «Доступно», не на кассу
- Погашение долга — отдельный расход
- Удалённые операции, долги, резервы и платежи не входят в расчёт
- Якорь месяца (`settings.month`) меняется только при переносе кассы, не при добавлении операции
- Удаление резерва **возвращает накопленное в кассу** (вывод), история операций сохраняется
- Если часы устройства ушли назад, openingBalance не пересчитывается
- Голосовой помощник и сброс оплаты тоже **мягко удаляют** записи — операции резерва не вырезаются
- В день зарплаты лимит считается на новый период (сегодня → день перед следующей зарплатой), а не «1 день»

## Нужные траты
- Лимит категории на период задаётся вручную и **не растёт** от экономии
- При закрытии периода (1-е число или день зарплаты) неиспользованный остаток лимита идёт в **накопления** — это учёт экономии, не новый лимит
- Повторное закрытие того же периода не начисляет накопления дважды
- Накопления **не обнуляются** при смене периода и сразу пишутся в снимок кассы
- Если приложение не открывали несколько циклов, пропущенные периоды закрываются по очереди — экономия не теряется

## Сохранность данных
- Локальное состояние шифруется (AES-GCM)
- Пока расшифровка не завершена, облако **не пишет** поверх кассы
- Если расшифровка не удалась — зашифрованный снимок не перезаписывается пустым состоянием
- При сбое ключа касса **восстанавливается** из Загрузки/Finna, локальных слотов или облака (явное восстановление снимает блокировку)
- Импорт JSON работает даже если локальный снимок не открылся
- 5 локальных снимков + файлы в Загрузки/Finna
- Облако не затирает живые данные пустым снимком
- Облако не помечает строку удалённой, если она просто ещё не доехала до другой копии
- Выход из облака не удаляет кассу на устройстве
- Облако не затирает лимиты и накопления, даже если операций ещё нет
- На двух устройствах накопления разных периодов **складываются**, а не затирают друг друга
- Автообновление APK **обязательно** проверяет SHA-256
- После перезагрузки телефона проверка обновлений ставится снова (включая Realme/Xiaomi)
- Фоновая проверка `update.json` не кэшируется и ставится точным будильником
- Веб-сборка больше не грузит `app.js` с CDN — в репозитории лежит полный файл
