# Копейка 3

Чистое PWA для учёта денег со сменами.

## Логика кассы
- **Баланс** = начальный остаток + доходы − расходы − депозиты в резервы (+ выводы)
- Остаток **не обнуляется** в новом месяце
- Долги влияют только на «Доступно», не на кассу
- Погашение долга — отдельный расход

## Облако
Тот же Supabase-аккаунт. Кнопка ☁ в шапке.
