# Копейка 3 / Финна

Личные финансы: смены, касса с переносом, резервы, долги, облако.

## Логика кассы
- **Касса** = начальный остаток + доходы − расходы − депозиты в резервы + выводы
- Остаток **не обнуляется** в новом месяце — переносится
- Долги влияют на «Доступно», не на кассу
- Погашение долга — отдельный расход
- Удалённые операции, долги, резервы и платежи не входят в расчёт
- Якорь месяца (`settings.month`) меняется только при переносе кассы, не при добавлении операции
- Удаление резерва **возвращает накопленное в кассу** (вывод), история операций сохраняется
- Если часы устройства ушли назад, openingBalance не пересчитывается

## Сохранность данных
- Локальное состояние шифруется (AES-GCM)
- Пока расшифровка не завершена, облако **не пишет** поверх кассы
- Если расшифровка не удалась — зашифрованный снимок не перезаписывается
- 5 локальных снимков + файлы в Загрузки/Finna
- Облако не затирает живые данные пустым снимком
- Выход из облака не удаляет кассу на устройстве
- Автообновление APK проверяет SHA-256
